Buscar Aluno

Dada uma lista de alunos, implemente um programa que permita buscar um aluno pela matrícula.

Se o aluno for encontrado, exiba seus dados.

Caso contrário, informe que o aluno não foi encontrado.

Utilize uma struct:

typedef struct tAluno {
    char nome[100];
    int matricula;
    float nota;
} Aluno;

Restrições:
- 1 <= N <= 1000
- Nome pode ter até 100 caracteres
- Nota entre 0.0 e 10.0
- Matrículas são inteiros

Entrada

A entrada é composta por um inteiro N — número de alunos.
N alunos: nome (string, sem espaços), matrícula (int), nota (float).
Um inteiro M — matrícula a ser buscada.

Saída

Se o aluno for encontrado:
Nome - Matrícula - Nota
Caso contrário:
Aluno nao encontrado

Entrada:

Ana 1 8.5
Joao 2 7.0
2

Saída: 
Joao - 2 - 7.00
