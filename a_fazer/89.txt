Carrinho de Compras

Implemente um programa em C para simular um carrinho de compras simples.

Cada produto possui:
- nome (string)
- código (inteiro)
- preço (float)

O programa deve:
1. Ler um catálogo com N produtos
2. Ler M operações de compra (código do produto + quantidade)
3. Montar o carrinho somando quantidades de um mesmo produto
4. Ao final, imprimir:
- os itens do carrinho (produto, quantidade, subtotal)
- o valor total da compra

Use structs:
typedef struct tProduto {
    char nome[100];
    int codigo;
    float preco;
} Produto;

typedef struct tItemCarrinho {
    int codigo;
    int quantidade;
} ItemCarrinho;

Restrições:
- 1 <= N, M <= 1000
- Quantidade >= 1
- Preço >= 0

Entrada

Um inteiro N — número de produtos.
N produtos: nome (string, sem espaços), código (int), preço (float).
Um inteiro M — número de operações.
M linhas contendo: código do produto, quantidade.

Saída

Para cada produto presente no carrinho, imprimir:
Nome - Quantidade - Subtotal
Ao final:
Total: X.XX

Regras:
- Se um produto aparecer mais de uma vez nas operações, somar as quantidades
- Subtotal = preço × quantidade
- Caso um código não exista no catálogo, ignorar a operação
- A ordem de saída deve seguir a ordem de inserção no carrinho (primeira vez que aparece)

Exemplo1

Entrada: 
2
Caneta 1 2.0
Caderno 2 10.0
2
1 3
2 2

Saída: 
Caneta - 3 - 6.00
Caderno - 2 - 20.00
Total: 26.00
