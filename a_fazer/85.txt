Cadastro de Alunos

Implemente um programa em C para gerenciar o cadastro de alunos.

Cada aluno possui:
- nome (string)
- matrícula (inteiro)
- nota (float)

O programa deve:
1. Ler os dados de N alunos
2. Armazená-los em um vetor de estruturas
3. Ao final, imprimir:
- todos os alunos cadastrados
- a média das notas
- o aluno com maior nota

Utilize uma struct:
typedef struct tAluno {
    char nome[100];
    int matricula;
    float nota;
} Aluno;

Entrada

A entrada é composta por um inteiro N — número de alunos.
N alunos: nome (string, sem espaços), matrícula (int), nota (float).

Saída

Imprima:
1. Lista de alunos no formato: 
Nome - Matrícula - Nota
2. Média das notas: 
Media: X.XX
3. Aluno com maior nota:
Melhor aluno: Nome - Nota

Exemplo1

Entrada: 
2
AnaSilva 1001 8.5
JoaoSouza 1002 7.0

Saída: 
Ana Silva - 1001 - 8.50
Joao Souza - 1002 - 7.00
Media: 7.75
Melhor aluno: Ana Silva - 8.50
