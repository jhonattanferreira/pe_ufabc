Sistema de Produtos

Implemente um programa em C para gerenciar um sistema simples de produtos.

Cada produto possui:
- nome (string)
- código (inteiro)
- preço (float)
- quantidade em estoque (int)

O programa deve:
1. Ler os dados de N produtos
2. Calcular o valor total em estoque
3. Identificar o produto mais caro
4. Permitir a busca de um produto pelo código

Utilize uma struct:
typedef struct tProduto {
    char nome[100];
    int codigo;
    float preco;
    int quantidade;
} Produto;

Restrições:
- 1 <= N <= 1000
- Preço >= 0
- Quantidade >= 0

Entrada

A entrada é composta por um inteiro N — número de produtos.
N produtos: nome (string, sem espaços), código (int), preço (float), quantidade (int).
Um inteiro C — código a ser buscado.

Saída

Imprima:
1. Valor total em estoque:
Total: X.XX
2. Produto mais caro:
Mais caro: Nome - Preco
3. Resultado da busca:
- Se encontrado:
Encontrado: Nome - Codigo - Preco - Quantidade
- Caso contrário:
Produto nao encontrado

Regras:
- O valor total em estoque é a soma de:
preco * quantidade
- Em caso de empate no preço, considerar o primeiro produto lido como o mais caro

Exemplo1

Entrada: 
2
Caneta 1 2.5 10
Caderno 2 15.0 5
2

Saída: 
Total: 100.00
Mais caro: Caderno - 15.00
Encontrado: Caderno - 2 - 15.00 - 5
